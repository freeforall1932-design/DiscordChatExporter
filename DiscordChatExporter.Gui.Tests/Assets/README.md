# Offline preview fixtures

The four 48×48 avatar fixtures are crops from this repository's existing public
`.assets/list.png` README screenshot. They are reused only to demonstrate the original
server-rail image controls without accessing Discord or a user's account.

`PreviewFixtures.cs` creates artificial guild/channel IDs and names. Its screenshot has
an explicit **SAMPLE DATA · OFFLINE PREVIEW** badge. No real server/account data is used;
no conversion or authenticated export is performed. These fixtures are not shipped as
product branding or represented as newly created artwork.
